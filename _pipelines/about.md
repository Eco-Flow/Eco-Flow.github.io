## About our pipelines

Our pipelines are generally written in **Nextflow**, and we try to follow **nf-core standards** as closely as possible. Pipelines hosted at https://github.com/Eco-Flow were developed using a basic **Nextflow/nf-core framework** for specific research projects, whereas those hosted at https://github.com/nf-core are part of the wider **nf-core community**. These follow stricter nf-core guidelines and are designed for broader use across the scientific community.

Not all our current pipelines are mentioned here, as some end-users prefer to keep them in private repositories until the paper is published. We encourage our users to publish as quick as possible, and be open with their code, although this is not always achievable.

### Custom config files

If you need a **custom configuration** to run nf-core, Eco-Flow, or your own Nextflow pipelines on your institution's computer infraestructure, we can build one for you.

Check the [nf-core/configs](https://nf-co.re/configs/) website for an existing configuration file for your institution. It should work for both **nf-core** and **Eco-Flow** Nextflow pipelines.

### Request a Pipeline

If you would like to request a pipeline, open a new GitHub Issue on our [pipeline discussions](https://github.com/Eco-Flow/pipeline-discussions) repository.

### Request a Feature

If you would like to request an additional feature for one of our published pipelines, please open a new issue on that pipeline’s GitHub repository.
